# 灵动舞台 · Dynamic Backdrop

Hermes Desktop 的本地动态背景插件：把界面变成一层薄纱，视频在最底下，所有面板共用同一套配色。

- **版本**：v1.0.0
- **插件 ID / 目录名**：`dynamic-backdrop`
- **平台**：macOS / Linux
- **适配 Hermes**：0.22.2（commit `d923a5eb`）
- **许可**：MIT

只在本机运行，不启动网络服务，不修改 Hermes 的配置、会话、Profile 或其他数据。

---

## 功能

### 背景

- 本地视频循环播放，或使用静态图片（MP4 / WebM / MOV / JPG / JPEG / PNG / GIF）
- 视频可见度与画面水平位置可调；视频比窗口窄时，决定露出哪一段
- 主窗口与 HUD 窗口共用同一套配色

### 外观

- **面板不透明度**：整窗底板浓度
- **气泡不透明度**：气泡、工具卡片、输入框、终端共用同一浓度
- **面板颜色**：只取色相，亮度会自动压到可读区间，因此不会因为选了浅色而让文字糊掉
- **文字阴影**：可选，只作用于直接压在视频上的文字；有自己底色的面板不受影响

### 多方案

保存多套互不干扰的配置，随时切换。

- **新建**：在方案列表里点「新建」，输入名称后确定
- **另存为**：以当前配置为起点复制出一个新方案
- **重命名**：名称创建后固定，可随时改
- **复制**：复制出的方案名带 ` 复制` 后缀，重名时自动加序号
- **删除**：至少保留一套方案
- **排序**：拖动行调整顺序
- **切换**：点方案名立即预览，按「应用」才真正切换

「保存」把改动写进当前方案的记录，「应用」才决定哪一套在运行 —— 两者分开，是为了让你可以改到一半先存着，不影响正在显示的界面。

### 轮换播放

让一组视频按顺序或随机切换。

- **两种模式**：「单视频」只用一个文件；「轮换」按列表播放。切换模式时另一侧的配置会保留
- **添加文件**：把路径粘贴到输入框，回车添加，一次一条
- **单独水平位置**：列表里每个文件可以有自己的画面水平位置，点该行的百分比修改；未设置时跟随全局
- **随机播放**：只影响挑哪个文件，不影响多久换一次
- **间隔**：1–1440 分钟
- **启动时切换一次**：每次启动应用时换下一个，间隔字段随之禁用
- **手动选择**：点列表里的文件名立即预览该文件；按「保存」记录，按「应用」保存并生效
- **拖动排序**：拖动行调整播放顺序

## 快速开始

### 安装

双击 `scripts/install.command`，或：

```bash
./scripts/install.command
```

安装时**不需要退出 Hermes**。插件装到应用级目录（不属于任何 Profile，切换 Profile 不会让它消失）：

```text
$HERMES_HOME/desktop-plugins/dynamic-backdrop/
```

安装脚本会先跑完四项检查，任何一项失败都不会覆盖现有安装：

- 文件与命名一致性
- 注入用的样式类与设计令牌是否存在于当前 Hermes 产物
- 跨平台路径处理
- 行为测试

如果已有旧安装，脚本会在替换前把 `plugin.js` 备份到 `$HERMES_HOME/desktop-plugin-backups/`。

安装完成后，如果界面没有立刻更新，在 Hermes 中执行：

```text
Cmd/Ctrl + K → Reload desktop plugins
```

### 卸载

```bash
./scripts/uninstall.command
```

卸载会先请求确认，再请 Hermes 正常退出（不会强制杀进程），等待其完全退出后才删除，最后验证删除结果。

卸载**不会**删除 Hermes 配置、会话、Profile、其他插件，或你指定的外部媒体文件。插件自己的设置记录也保留 —— 重装即可恢复；想彻底清掉，用设置页的「清理配置」。

## 打开设置

三种方式：

- 侧边栏的「灵动舞台」入口
- `Cmd/Ctrl + K` → 「打开灵动舞台设置」
- 直接访问路由 `/dynamic-backdrop-settings`

同一个命令面板里还有两条命令：

- **重新加载背景视频**：替换了同路径的视频文件之后用。`<video>` 会一直持有已加载的媒体，路径不变就不会重读，这条命令会强制重新读取
- **检查灵动舞台兼容性**：不需要进设置页就能跑一次检查

## 设置项

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 启用灵动舞台 | 开 | 关闭后恢复 Hermes 原本的界面外观 |
| 视频文件 | 留空 | 留空则使用插件目录里自带的默认视频；可填绝对路径 |
| 视频可见度 | 25% | 视频层本身的亮度，0% 等于隐藏视频 |
| 画面水平位置 | 25% | 视频比窗口窄时，决定露出哪一段 |
| 面板不透明度 | 25% | 整窗底板浓度，影响整页观感 |
| 气泡不透明度 | 75% | 气泡、工具卡片、输入框与终端共用 |
| 面板颜色 | `#9ea0db` | 只取色相，亮度会自动压到可读区间 |
| 文字阴影 | 关 | 给压在视频上的文字加一层深色描边；面板内的文字不受影响 |
| 播放方式 | 单视频 | 单视频与轮换二选一，切换时另一侧配置保留 |
| 轮换：随机播放 | 关 | 只影响**挑哪个文件**，不影响多久换一次 |
| 轮换：启动时切换一次 | 关 | 开启后每次启动换一个，间隔字段禁用 |
| 轮换：间隔 | 10 分钟 | 1–1440 分钟；「启动时切换一次」开启时不可用 |
| 轮换：画面水平位置 | 跟随全局 | 每个文件可单独设置，点列表中该文件的百分比修改 |

上表的默认值同时是**全新安装**和**清理配置**之后落到的状态。

设置页底部四个按钮排成一行：

- 左侧：**保存**（写入当前方案）、**应用**（保存并让它生效）
- 右侧：**检查兼容性**、**清理配置**
- 右下角显示构建日期与版本号

### 清理配置

「清理配置」会删除本插件在 Hermes 存储里的全部设置记录，让插件回到默认状态 —— 用于配置因意外情况变得不可用时手动复位。

- 点击后**还会再确认一次**，确认框里写明将删除多少条、属于哪个命名空间
- 删除范围经过两道判定，**不可能误删其他插件或 Hermes 自身的设置**
- 删除后立即以默认值重新渲染，不会把刚清掉的记录又写回去

## 兼容性检查

设置页打开时会自动检查一次，结果直接显示在按钮旁边；按「保存」或「应用」前也会自动检查。

检查内容：插件 SDK、主内容区、侧栏、背景媒体加载，以及样式是否可以安全应用。

| 结果 | 表现 |
| --- | --- |
| **兼容** | 全部效果正常启用 |
| **部分兼容** | 背景继续显示，无法识别的部分效果关闭并通知 |
| **不兼容** | 进入安全模式 —— 移除自身媒体、样式与 class，恢复 Hermes 原有显示并通知 |

检查结果会一并给出运行中的 Hermes 版本与本插件的适配版本。**版本不一致只提示、不阻止使用**：插件真正依赖的不是版本号，而是应用产物里那些具体的样式类与令牌，每次安装和检查都会逐个核对。

`dynamic-backdrop/` 下的 5 个 mp4 就是内置视频库：`默认视频.mp4` 是路径留空时播放的那一个，其余为轮换可选的素材。文件原名不重要，插件按目录内实际存在的文件工作。

安装脚本在复制文件**之前**会跑全部四项检查，所以坏构建不会覆盖可用安装。

## 使用提示

- **替换同一个路径的视频文件后不会自动生效**。`<video>` 持有已加载的媒体，插件只在 URL 字符串变化时才重新赋值。用命令面板的「重新加载背景视频」强制重读
- **改完插件要重载才生效**：`Cmd/Ctrl + K → Reload desktop plugins`。设置页底部的构建日期用来确认实际在跑哪一版
- **内置视频库**放在插件目录下，路径留空时按内置默认视频播放；想用别处的文件，在「视频文件」里填绝对路径
- **数字输入框**只接受数字，超出范围的输入会停在边界值；右键可以粘贴，插入光标处而不覆盖原有内容

## 性能

视频播放会消耗少量 CPU/GPU。出现卡顿或功耗增加时，可以：

- 降低视频可见度
- 使用分辨率较低的视频
- 改用静态图片
- 关闭插件
